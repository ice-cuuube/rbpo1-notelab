# Датасет анализа безопасности NoteLab

## Назначение

Датасет содержит результаты учебного анализа проекта NoteLab
и локального веб-сервиса, запущенного на виртуальной машине Linux Mint.

## Структура

- `data/scan_findings.csv` — единый набор выявленных результатов;
- `data/raw/` — исходные результаты инструментов;
- `meta/scan_findings.meta` — метаданные;
- `report/expert_assessment.md` — экспертная оценка;
- `report/sources.md` — использованные источники.

## Проект

NoteLab — учебный менеджер заметок на Python.

## Инструменты

- Git
- Nmap
- Masscan
- Nikto
- Horusec
- jq
- prips

## Область анализа

Сканирование сетевого сервиса выполнялось только
на собственной виртуальной машине Linux Mint.
