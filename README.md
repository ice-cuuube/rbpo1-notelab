# NoteLab

NoteLab — учебное веб-приложение для создания и просмотра текстовых заметок.

## Назначение

Проект разработан в рамках практической работы №1
по разработке безопасного программного обеспечения.

## Возможности

- просмотр заметок;
- добавление заметок;
- хранение данных в JSON;
- HTTP API;
- локальный запуск на Linux Mint.

## Используемые технологии

- Python 3;
- HTTP Server;
- HTML;
- JavaScript;
- JSON.

## Запуск

```bash
python3 app.py
